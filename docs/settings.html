Settings and setup

Is everything working, what the bot is set to, and how to change it.

System check

The bot checks itself on every run. It only reports whether your Telegram secrets exist; their values are never saved or shown anywhere.

Current settings

Indices and your broker's contract specs

Change settings

Settings live in config.json in your GitHub repository. Fill in this form, build the new file, then paste it into GitHub. The next bot run uses it.

Find the specs in MT5: Market Watch → hold the symbol → Specification. Contract size is the money per point for 1 lot. Leave a row's three numbers empty to keep "size per point" messages for that index.

Open config.json on GitHub ↗
  1. Click Copy, then Open config.json on GitHub and sign in if asked.
  2. On GitHub, click inside the file, press Ctrl+A, then paste with Ctrl+V.
  3. Click Commit changes…, then Commit changes. The next run uses the new settings.

If something goes wrong

What you seeWhat to do
No morning messageCheck the System check above. Then cron-job.org → your morning job → history (it should show 204), and your repository's Actions tab for a failed run.
"⚠ today's bot run failed"Open the link in that message and read the red step. The bot retries at the next scheduled time on its own.
cron-job.org shows 401The GitHub token expired or was pasted wrongly. Regenerate it, paste Bearer github_pat_… into the Authorization header, and update the expiry date here.
cron-job.org shows 403 or 404The token needs Actions: Read and write on index-signals, and the URL must end in /actions/workflows/daily.yml/dispatches.
A reply wasn't confirmedReplies are read at the next run (morning or about 8:20 pm). Use the index names exactly as in the messages, for example filled US100 19940.
"no new price … yet"A market holiday or a delay at the price source. The next run catches up.
"below your broker's minimum"The planned size is smaller than the smallest lot. Use a larger demo balance (reply balance AMOUNT) or accept skipping it.

For the daily routine and the reply commands, see How it works.
