How to get the token (once, about 2 minutes)
  1. Open GitHub → New fine-grained token ↗.
  2. Name it website index-signals and pick an expiry (up to 1 year).
  3. Repository access: Only select repositories → index-signals.
  4. Permissions → Repository permissions → Contents: Read and write. Leave the rest.
  5. Generate it, copy it, and paste it above.

The token stays in this browser only. It can change files in this one repository and can't read your Telegram secrets. Use Disconnect on a shared device, and you can revoke it on GitHub at any time.
